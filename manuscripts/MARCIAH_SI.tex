\section{Minimal Command-Line Test}

The executable MARCIAH distribution provides a minimal command-line test. The test is launched through \texttt{scripts/run\_cli\_example\_test.sh}, uses the bundled ligand and complex production logs, runs \texttt{analyze\_LIE\_noqgui.py}, and writes a CSV file with the resulting LIE estimate under \texttt{results/}.

\section{Software Environment}

The Python-side dependencies used by the analysis scripts are defined in the root-level \texttt{environment.yml} file of the MARCIAH repository. Installation is automated through \texttt{scripts/setup\_conda\_env.sh}, which creates the \texttt{marciah-q6-lie} Conda environment.

\section{Required File Classes}

The workflow requires ligand and complex inputs that are compatible with Q6. At minimum, one calculation uses ligand and complex topology files, ligand library and parameter definitions, FEP files, equilibration restart files or the inputs needed to generate them, production input files, and production log files for the final LIE analysis step.

\section{Directory Schema}

The executable repository is organized around \texttt{ligands/}, \texttt{complex/}, root-level analysis scripts, and \texttt{scripts/} for installation and CLI testing. The root \texttt{README.md} documents the execution sequence used by the bundled example.
